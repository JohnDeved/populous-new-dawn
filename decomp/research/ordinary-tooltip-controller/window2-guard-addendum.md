## Result

The record2 configuration guard belongs to a context-selected topic window with its own mode and input routing. `0045ed10` selects a topic from the HUD, picked object or ground; the retained `0045ddf0` renders an illustration keyed by the same topic. Calling this a contextual help window is an inference from those behaviors, not a recovered title/text string. The browser's Help/Menu button opens a general settings dialog with static control instructions; ordinary pause and overview have separate owners. None of these current lifecycles implements the demonstrated native saved-mode/configuration/context-topic combination.

The important input correction is exact: while mode is `0x11`, the first F1 release binding resolves to case `0xb9`, before the later ordinary inspection release binding `0x73`. A generic paused/dialog boolean cannot stand in for this routing. This is a source-supported difference in ownership, not evidence that a particular captured-pointer browser event is delivered at runtime.

## What the immediate context selector actually writes

`0045ed10` is complete through return `0045ef3f`; jump-table bytes are retained separately as data. It starts with candidate=-1. If `0044b060()` is nonzero, it takes the HUD branch: positive owner0098db0c uses signed16 field at `0068459b+113*owner`, falling back to topic0x416 when that field is zero. A nonpositive HUD owner leaves no candidate. It does not proceed to world picks in that branch.

Otherwise it resolves primary ID0087cac2, then secondary ID0087cace, rejecting zero, object flag+0xc bit1, or class+0x2a zero. With neither object and valid-cell bit0087cabc&1, it computes the even-cell pointer from packed0087caba. Cell flag0x200 allows a contained object. For a found object, class1 and class2 use model-indexed DWORD topic tables0059d7f4/0059d814; class3 leaves no candidate; class4 chooses0x3e1/0x3e2 from model-table flag; class5 uses its bounded model/subtype switch. Without a qualifying contained object, cell flag0x10000 selects0x3dc; otherwise the terrain-type table can permit0x3db.

Only a nonnegative candidate changes the topic. At `0045ef07–0045ef3a`, it passes `(old00749e08-0x3d7)` with ECX00749ec0 to `00425140`, stores the new topic in00749e08, clears00749e10, and calls0048a050 with `(0,0x6a,0x801)`. No candidate preserves the existing topic and field00749e10. The enable owner still sets configuration/mode afterwards. The callees' effects were not expanded or replaced with guessed history/audio semantics.

Retained `decomp/generated/0045ddf0.c:37–136` consumes00749e08 to choose and render person, building, vehicle, scenery or HUD illustrations. Its community/decompiler name `d3d_exec_create` is not an authoritative UI label. The actual window2 title/text presentation and its dispatch to this illustration consumer are not bound by this finite pass. No contextual-topic browser owner is demonstrated by the current static Help/Menu dialog.

## Stop boundary and acceptance

The finite producer/guard question now has a concrete answer: this is an additional context-topic/mode owner, not a proved synonym for current browser menu, pause or overview. **No complete ordinary inspection or tooltip runtime scope is accepted.** The observed absence cannot justify dropping the original interaction history or treating an explicit-Hut action as fully independent of cache acceleration.

The smallest remaining direct native question is `004513d0` and its active-window producer, which controls repeated enable/outside-window behavior while configuration is set. To implement the contextual window itself, separately bind the window2 title/text presenter and its00749e08/00749e10 consumer dispatch. Those are named missing owners, not authorization for a broad window/input survey. Other previously retained gaps remain: level/land flags and valid-cell producers, mode writers beyond0047a550, shared T initialization from HUD/cells, forced-expiry handled ownership, and fresh/reused inspection-record effects. No fixed-Hz adapter, panel-only compromise or generalized input rewrite is proposed.
