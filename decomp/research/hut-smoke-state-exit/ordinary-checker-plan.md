`hut-smoke-ignition-observer.mjs` wraps only the existing renderer method. Every call invokes the original once with its original receiver and arguments. Only an actual main-scene/camera return is observed. The observer copies state and records three PNG readbacks synchronously after actual draws: a full-root baseline, the first state4 frame, and the first state4 frame with no residents. It never advances animation, invokes render, cancels RAF, changes game state or pauses the game. Ordinary Pause is clicked after the event has been observed; the retained PNG and paired sample refer to the actual earlier draw, not a claimed pause timestamp. If the first burning draw is already at timer119 or later, the checker fails with a capture gap.

Each retained sample contains the real renderer frame serial, simulation turn, state/progress/timer, actual living resident IDs, admission slots, root record plus slot/serial, independently owned child records/positions/lifetimes, visibility, original atlas object/frame/UV metadata, both RNGs and the secondary animation frame. Child preservation is established by the focused native/live evidence; the ordinary observer records children without requiring a random child emission or changing RNG. Root absence and unchanged residents must coexist in the actual rendered early state4 frame. Later ordinary evacuation must still remove the residents without recreating a root. The observer holds at most 256 turn/pause samples, three PNGs and eight errors; ownership is checked on restoration.
