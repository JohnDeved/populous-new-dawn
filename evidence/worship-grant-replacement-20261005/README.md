# Ordinary spell-gift replacement proof

Frozen source [d0666bae45421da88690d14d528385054cea4cb2](https://github.com/JohnDeved/populous-new-dawn/commit/d0666bae45421da88690d14d528385054cea4cb2). [Research note](https://github.com/JohnDeved/populous-new-dawn/blob/d0666bae45421da88690d14d528385054cea4cb2/decomp/research/worship-grant-replacement.md).

Three original-byte cases replace a Bridge controller with a distinct Lightning gift before pulse/arrival, with an existing pre-arrival pulse, and after the first arrival clamp. Both rewards pay exactly once; immediate pulse bytes remain unchanged; only the new controller owns the new handle. The independent reviewer accepts the bounded result and matches every state/event row.

Raw receipts are losslessly compressed JSON. The manifest records source, consumed input and raw evidence hashes. UI/object visits remain separate clocks; this is not natural elapsed-time, same-turn callback order, native GPU pixels, complete list removal or a live implementation.
