# Capture/offline membership observation read surface

The current proposal supersedes the failed detached-wire method prospectively.
No historical failure is relabeled. New qualification statuses belong in the exact
source-bound receipt; no gameplay replay follows automatically from passing tests.

## Live surface

snapshot serializes the entire world and enforces16MiB, copies the current task
and scalar turn/queue/RNG metadata, then compares the entire world again in finally.
It calls no production helpers and performs no registry/person/Unit projection.
The before/after live byte guard, original error event and first-rejection buffers
are unchanged. Only a positive final dispatch writes that already-guarded raw
buffer once. All other stages retain only metadata. A value-equivalent but byte-
different result still fails; no noncanonical wire mismatch is exempted.

The original function bodies remain intact. The exact declaration wrapper calls
stepComputerTasks once and snapshots after it returns. Its type20 branch performs
the complete select-action loop before return. select/selectShaman callbacks are
wrapped only at consumed calls and returned once without replay. The controller
return is passed back unchanged. Captured file writes are outside world state.

## Offline surface

project-phase3.mjs imports only built-ins. It requires terminal exit0, source/input
guard success and receipt-bound hashes for capture/JSONL/summary. Its own file hash
must match the live run's QA source record. The capture hash/size and task/turn must
match the single positive final-dispatch record. All files are rehashed after the
projection. No captured world file is modified or restored into a running model.

The existing pick/aliases/registeredPeople helpers use plain property reads, Map
entries, array construction and ordinary identity comparison within one decoded
graph. Record every registered class1/tribe2 row without hp/member/model/assignment
filtering; include all six aliases (native, fight.motion, flight, entry.person,
builder.person, resident.person), stale references and unmatched registry entries.
No terrain, collector, order, selector, decoder outside Node v8 or runtime helper
is invoked. Original typed-view backing is irrelevant to these membership fields
and remains unproved.

A finite shape check accepts ordinary registry/person/Unit objects and required
numeric membership fields, rejects unsupported values/accessors/objects explicitly,
and retains missing optional fields as labelled absence. It does not generalize
world equality or compare arbitrary graphs. Unknown native flags never become0.

## Seven controlled contracts

All fixtures are supplied ordinary data, with no production/dependency import or
createWorld/tick. The exact source-extracted snapshot/controller/dispatcher wrappers
are used; the offline helper is imported directly as a built-in-only module.

1. Capture→decode complete cohort: unlisted hp0/model4, unmatched models5/7,
   ID/key-mismatched model6, registered resident/entry owners and stale native
   aliases survive; foreign tribe/class controls stay excluded.
2. Actual observer wrapper contract: one selector/controller/dispatcher call,
   unchanged return, separate callback/controller metadata, exactly one capture
   after all supplied select actions; offline decoding sees their state14 result.
3. Throwing metadata-copy mutation: retain original error and strict live rejection.
4. Ordinary live mutation: reject with full buffers, no terrain exemption.
5. Oversized world: stop before metadata copying.
6. Combined capture cap: reject before a write; never expand output limits.
7. Unsupported membership field: typed/string/NaN state inputs fail offline while
   the immutable capture bytes remain unchanged.

Controlled action effects do not prove production gameplay. Capture bytes and
rejection pairs remain local; JSONL+capture+cohort≤32MiB, rejection pair≤32MiB,
summary/stdout/stderr/receipts≤1MiB each, total≤68MiB. Full native admission,
specialist maintenance, original backing topology and Mission1–3 remain unproved.
