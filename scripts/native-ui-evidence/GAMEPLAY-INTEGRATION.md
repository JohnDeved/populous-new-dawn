# Disabled gameplay diagnostic integration

New source-only proposal. The two diagnostic choices are deliberately rejected before checkout/install; no input or environment switch can admit them. Existing kinds, concurrency and runtime remain unchanged. This is not a browser runner or a completed resource gate.

The append-only bounded phase journal is groundwork for a future independently reviewed adapter. Its caller must own a physical exclusive output path, preserve the primary error when recording a secondary failure, close the journal in finally and independently enforce process/output budgets. Fsync confirms writes to the OS, not durable remote retention. The module neither admits resources nor verifies browser cleanup.

Two focused tests are included but not executed at initial publication; syntax checks only. Whole-adapter, filesystem-failure, process cleanup and real browser tests remain required. No Spy module is incorporated until its pending abort-continuation repair receives fresh independent review. Swamp public input/casting and rendered validation remain unimplemented.
