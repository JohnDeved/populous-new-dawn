## Accepted behavior and source limits

through the existing conversion callback before conversion. Admission owns the
shared record, separate Scene latch and deduplicated reservation synchronously.
Failed allocation leaves the latch clear for retry. Phase-1 renewal and phase-2
reuse retain the existing lifetime; fresh phase -1 reserves capacity but waits
for the normal controller opportunity before painting.

The existing Preacher progress UI consumes that record. While training activity
is set or its automatic record exists, legacy hover/activity paint yields to the
record, including capacity failure and fresh entry. Manual retained admission
remains Hut/Camp-only. Inactive Temple hover/held controls and independent
dismantling remain supported; held controls cannot freeze automatic retirement.
Existing Scene/load ownership applies without adding World serialization or
changing clocks, conversion, assets or other training-school families.
