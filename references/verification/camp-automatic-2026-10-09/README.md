## Accepted behavior and limits

A completed, living, local class 2/model 7 camp requests its shared automatic panel
at the existing live training callback, before conversion and subsequent allocation.
A transient Scene binding owns the separate successful-admission latch. Failure
leaves it clear for retry; manual reuse preserves phase, hold and D. Phase1 renews
while active, then clears the latch on expiry. Phase2 reuse does not restart exit.
A fresh phase -1 record reserves capacity immediately and waits for the existing
controller step before painting. Bare activity 0x80 no longer creates camp DOM.

Save preserves the current Scene owner. Load/new Scene clears transient ownership;
saved flags3 bit23 cannot suppress the next genuine request. Independent DOM hold
and dismantling 0x8000 remain browser adapters. Held controls cannot freeze automatic
expiry. Three manual tests deliberately moved their old activity-based independent
paint expectations to that dismantling adapter; current assertions are not described
as unchanged from the historical seven-test baseline.
