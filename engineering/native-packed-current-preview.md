# Native packed cache preview on current main

Baseline: 2b62ee869d4531873d9633031f3ce04f6c1424b8. Selective source: held PR551 head 506851983e9443a9d088a34260528b0b5fa5d6a5. This is a testable composition, not a merge or performance acceptance. The historical failed whole-workload gate remains a hold; this preview neither replaces that evidence nor claims a speedup.

Only native packed source-ID slots and exact equal-grid-corner sharing are transferred. Native queries retain original submitted triangle IDs and ordering, never update terrain visibility, and resolve current painter ownership/depth after geometric candidates. Cache hits may fill newly submitted IDs; the corner map is new for that query, so a new ID cannot alias a previous query's corner based on grid location alone. Position identity/version, existing key and packed/sparse representation eligibility control reuse exactly as the held source. Sparse/custom layouts retain the fallback. Version1 reason fields remain non-exhaustive for representation-only changes.

Modern ordinary scratch leases, scalar scan evaluation order, visibility counters and model-work diagnostics remain intact. Only ordinary nonnested queries lease scratch; native retained world/screen/slot buffers never use that lease. Ordinary queries continue recomputing geometry. Integration tests cover native→ordinary and nested native calls, retained buffer identity, failed native rebuild publication and subsequent recovery.

Validation uses an untouched baseline worktree and explicit PND_TERRAIN_BASELINE. The shipped-camera matrix compares full ordered native and ordinary candidates and winners over 1,296 queries, including diagonals, camera/zoom/overview changes and live water. Additional retained tests cover sparse IDs, submissions reordered/added/removed, newly added aliases after unversioned mutation, custom/interleaved/normalized/shared fallback, versions, custom getters, nonfinite/near-collinear scan behavior, ownership and F8-off clocks. No browser/timing results are implied.

Prospective measurement must be reviewed separately: bind exact base/candidate trees, fixture/helper/assets, and compare full pointer update or callback work (including key creation, slot/corner construction, projection, scan and current painter resolution), not projection math alone. Use fixed moving-view cache-miss, static cache-hit, changed-submission and fallback cohorts with complete ordered candidate/winner parity before timing. Report whole workload distributions and retained memory, preserving unfavorable tails and the historical hold. Do not infer wins from operation counts or unmatched gameplay captures. Raw recordings and logs remain private/untracked.
