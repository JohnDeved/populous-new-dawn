## Exact scope and entry point

`spellAngel({ browser, url, output, source, expectedRevision, deadlineAt })` in
`scripts/tutorial-browser/angel-visuals.mjs` owns one fresh context. Admission
requires at least 60,000 ms remaining on the caller's absolute deadline. One
50,000 ms monotonic clock starts **before context creation** and includes fixture
creation, public UI, observation, evidence retention and context closure. Failed
admission is a failure, not a skip. Late-created/late-closed contexts retain failed
status and pending cleanup until closure is observed.

The supplied current-v4 Mission 1 setup uses flat dry native height135, an explicit
isolated-controller gate, four owners with nearby reserved victims, an invisible
camera-anchor Shaman excluded from targets, a native model neighbour and finite
Angel lifetime80. Four actual production24Hz preparation visits place all four
Angels in a genuine displayed69→77 transition. This is neither an authored encounter
nor earned stock. Ordinary lifetime2500 is not changed in application code.

1. Losslessly write/read the supplied current-format fixture in a fresh IndexedDB.
2. Public main-menu Load, with a declared setup-only pause-property latch to retain
   the exact migration boundary. Remove that latch before any Save interaction.
3. Observe ordinary paused rendering and exact displayed/next state stability.
4. Public Game settings → Save Game → Save checkpoint. Read the actual committed
   current-v4 record and retain its complete graph, both RNGs and Angel state.
5. Public Load Game → Load checkpoint. Capture the exact synchronous replacement
   boundary without a second latch, pause injection, fake tick or manual render.
6. Observe ordinary resumed rendering through both bases, transitions, shrinking
   death and expiry. Require owned geometry/material disposal, no shared atlas
   disposal, a still-submitted native neighbour and cleared-footprint crops.

A read-only RAF observer captures mutable mesh positions, actual GPU UV attributes,
white material color, atlas identity, submitted shader scale, native projected
bounds and world height. The native half-texel/31-pixel sampling transform is part
of the UV oracle, not just raw imported UV translation. A real mesh-factory test
cross-checks that oracle. First eligible case slots are fixed before crop admission;
an obscured/missing case fails, rather than replacing it with a convenient later
frame. Canvas pixels are copied synchronously in the observed render callback.
PNG encoding/readback happens only during retention of those immutable copies.
The three contextual images and ordered morph crops are labeled as supplied-fixture actual rendering on the tested commit for PR presentation; they are not mockups.
Bounds: 12,000 RAF callbacks, 1,200 state samples, 20 crops per segment, 256×256
maximum crop, one1440×1000 paused screenshot plus two full-scene same-render sequence frames (at most1440×1000). Exceeding a cap fails.

## Hosted shard and trusted admission

The authorized ninth `spell-visuals` matrix row keeps the existing eight rows and
limits intact. Its browser cap is180s, build cap120s and hosted job cap15min. It
adds no permissions, secrets, unsafe browser options or new trigger types. The
runner owns the browser/server; the episode owns only its fresh context. There is
no F9 work and no compact/picking/Hypnotise contention.

Currently the exact required episode inventory is `['angel']`. The insertion
point for a separately accepted Shield episode is after successful awaited Angel
closure. A future45s Shield episode with55s admission fits after the worst-case
50s Angel episode, leaving85s of the180s browser allowance. It must be integrated
by updating the explicit source/artifact/episode contract, never by treating an
absent or failed Shield episode as optional success.

The existing eight-job validator and parent trusted reader remain unchanged.
`spell-visuals-nine-v1` is a **new explicit opt-in** contract in
`scripts/integration-queue/spell-visuals-policy.mjs`. It requires all nine named
successful jobs, exact attempt/head, every required step and source pins. It never
chooses a weaker policy by job count or candidate-reported success. Parent admission
must separately review/deploy the data-only policy, renderer oracle, ZIP reader,
checkpoint codec and pinned original JSON. No trusted-copy activation is included.

The compact receipt binds actual raw host/episode JSON, supplied and publicly saved
checkpoint graphs, exact public Load boundary, every crop and context screenshot.
The trusted data-only oracle independently reconstructs signed-short morph geometry,
owner UVs and texel-center mapping from caller-pinned original JSON, not candidate
application execution. PNG validation checks CRCs, dimensions, bounded inflate,
filters and decoded pixel checksums/colors. The numeric artifact ID/name/size/digest
must additionally be bound by the parent's authenticated job upload log and API
metadata before the bounded data-only archive resolver is used.
