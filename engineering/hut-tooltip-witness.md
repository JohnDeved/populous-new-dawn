## Checkpoint and cleanup contract

Save observation follows the trusted click and captures the first synchronous
store publication, after `saveCheckpoint` rebuilds lists and clones the World.
The typed complete record digest must equal actual committed IndexedDB exactly.
This raw record can contain transient UI reservation strings. Load observation
captures the replaced World before `beginLoad` automatically resumes it.
`restoreSecondaryEffects` explicitly clears saved transient reservations; this
is asserted separately from the stable actor/terrain/stock/turn/time comparison.
The full loaded digest is retained, but raw-record equality is not claimed.
Presentation record maps/queues are recreated; the page session sample/cache is
retained. Save itself must not be described as serializing the new scene records.

Continue Game has an arrow-bearing accessible name and only closes the browser
dialog; Resume game is a separate conditional action. Browser Help is not the
native Encyclopaedia. Scene/disposal cleanup restores only owned wrappers and
listeners, preserves foreign replacements and retains the original failure even
when cleanup/persistence also fails. All diagnostic errors fail evidence without
stopping the next game callback.

The panel-control phase checks an existing control's physical pointer ownership,
the same retained record identity and visible control beyond its normal hold.
Leaving returns to the already planned Blast destination and awaits normal
expiry; no control is clicked or focus injected. This is the explicit browser
usability retention adapter. Encountered `unsupportedHistory` routes, including
native-unbound panel/status ownership, remain visible and outside native credit.
